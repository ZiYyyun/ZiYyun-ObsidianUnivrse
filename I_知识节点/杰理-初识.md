

### SDK的目录结构


| 目录                   | 主要功能           |
| -------------------- | -------------- |
| apps/                | 各类应用、产品方案      |
| apps/common          | 各类工程共用代码       |
| apps/common/example/ | 外设及系统功能示例      |
| cpu/                 | 芯片平台相关代码、链接配置等 |
| cpu/liba             | 平台相关预编译库       |
| lib/                 | 对外开放的库代码       |
| include_lib/         | 库提供的公共头文件      |
| doc/                 | 数据手册、技术资料      |
| tools/               | 编译烧录等相关工具      |
