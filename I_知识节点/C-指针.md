### 指针的定义

### 指针的声明
**典型错误纠正**：  
`int *p = 89;` 中 `p` 存储的是**地址89**（十进制），而非让 `*p` 的值为89。  
正确做法：`int x=89; int *p = &x;`（此时 `*p` 才是89）。

### 指针的符号
`*(&变量) ≡ 变量` 且 `&(*指针) ≡ 指针`（二者互为逆运算）。

| 符号   | 含义             | 关键特性                |
| ---- | -------------- | ------------------- |
| `a`  | 变量本身的值         | 普通变量：存储数据；指针变量：存储地址 |
| `*a` | `a`指向的地址里的数据   | 仅当`a`是指针时有效！        |
| `&a` | `a`这个变量在内存中的位置 | 永远返回地址（十六进制形式）      |





### 一个demo


> [!NOTE] 指针+数组 题目
> 要求写出一个完整 C++ 程序：
>```
>int arr[5] = {10, 20, 30, 40, 50};
>```
>再定义：
>```
>int *p = arr;
>```
>然后完成：
>1. 输出 `arr[0]`
>2. 输出 `*p`
>3. 让 `p` 移动到下一个元素
>4. 输出此时 `*p`
>5. 输出 `*(p + 2)`



> [!NOTE] 指针的后移
> 当我们写：
> ```c
> p++
> ```
> 的时候，C++ 的指针加减会自动按照它所指向的数据类型移动


所以，最终程序：

```cpp
int main(int argc, char** argv) {
	int arr[5] = {10, 20, 30, 40, 50};
	
	int *p = arr;
	
	cout << arr[0] << endl;
	cout << p << endl;
	cout << *p << endl;
	
	p++;
	
	cout << *p << endl;
	
	//----------------------------------
	cout << (*p + 2) << endl; //[!NOTE] p指针先解引用，再加2
	cout << *(p + 2) << endl;  //[!NOTE] p指针先后移2个单位长度，再解引用
	
	return 0;
}
```
