### 核心架构
- **射频前端（RF）**：负责接收和处理微弱的卫星射频信号。
- **数字基带处理器**：负责卫星信号的捕获、跟踪与解调。
- **32位 RISC CPU**：主频可达 104MHz，负责运行定位解算算法。
- **电源管理模块（PMU）**：内置 DCDC 和 LDO，提供灵活的供电方案。

### 主要特征
- 支持 BDS/GPS/GLONASS 多系统联合定位和单系统独立定位。 
- 支持北斗二号/三号 1-63 号全部卫星。 
- 具备有源天线检测与保护。 
- 电源管理内部集成 DCDC 和 LDO； 支持 2.7~3.6V 单电源供电（使用内部 DCDC）或 1.8V~3.3V 单电源直接供电（不使用内部 DCDC）。 
- RTC 和备份电路电源可低至 1.4V。 
- 功耗： BDS/GPS 双模连续运行：23mA@3.3V。待机：8uA（@3.3V）。 
- 封装尺寸： QFN40，5mm×5mm×0.9mm


### 引脚接口

| AT6558R 引脚 | 主控（MCU）引脚 | 说明                     |
| :--------- | :-------- | :--------------------- |
| TXD        | RXD       | 芯片发送 NMEA 定位数据给主控（最核心） |
| RXD        | TXD       | 主控发送配置指令给芯片（如改波特率，可选）  |
| GND        | GND       | 共地（必须连接，否则信号不稳）        |
| VCC        | 3.3V      | 供电（注意：切勿接入5V，否则烧毁芯片）   |
另有：
- **1PPS**：秒脉冲输出引脚。每秒输出一个高电平脉冲（脉宽约100ms），用于**高精度授时**，可接入MCU的外部中断或定时器捕获引脚，将系统时间误差校准到纳秒级。
- **STANDBY / EN**：电源控制引脚。拉低进入超低功耗待机模式（8μA），拉高唤醒，适合电池供电设备。

在主控端配置 UART 串口时，请使用以下**默认参数**：

- **波特率**：**9600 bps** （新手最常踩的坑：配成了115200导致收到乱码）
- **数据位**：8 bit
- **停止位**：1 bit
- **校验位**：无 (None)
- **流控**：无


### 数据结构
AT6558R 会源源不断地通过 TXD 引脚输出 **NMEA 0183 协议** 的 ASCII 文本字符串。  
数据以 `$` 开头，以 `\r\n` (回车换行) 结尾，中间用逗号 `,` 分隔数据段，`*` 号后面跟着两位十六进制的**校验和**。

>`$GNRMC`（最小定位信息）数据----最常用
```c
$GNRMC,083559.00,A,4717.11437,N,00833.91522,E,0.004,77.52,091202,,,A*6F\r\n
```

| 字段序号 | 示例值           | 含义与说明                                                            |
| :--- | :------------ | :--------------------------------------------------------------- |
| 0    | `$GNRMC`      | 语句头                                                              |
| 1    | `083559.00`   | UTC时间：08时35分59.00秒。（北京时间需 +8 小时）                                 |
| 2    | `A`           | 定位状态：`A` = 有效定位 (Active)；`V` = 无效/未定位 (Void)。（最重要字段，V时后面的经纬度不可信） |
| 3    | `4717.11437`  | 纬度数值：格式为 `ddmm.mmmmm`（度+分）。47度 17.11437分。                        |
| 4    | `N`           | 纬度半球：`N` = 北纬，`S` = 南纬。                                          |
| 5    | `00833.91522` | 经度数值：格式为 `dddmm.mmmmm`。8度 33.91522分。（注意经度是3位度数）                  |
| 6    | `E`           | 经度半球：`E` = 东经，`W` = 西经。                                          |
| 7    | `0.004`       | 对地速度：单位为“节”（Knots）。1节 = 1.852 km/h。                              |
| 8    | `77.52`       | 对地航向：真北为0度，顺时针计算（0~360度）。                                        |
| 9    | `091202`      | UTC日期：09日12月2002年（ddmmyy）。                                       |
| 10   |               | 磁偏角（度数），通常为空。                                                    |
| 11   |               | 磁偏角方向（E/W），通常为空。                                                 |
| 12   | `A`           | 定位模式指示（NMEA V2.3+新增）：`A`=自主定位，`D`=差分，`E`=估算，`N`=无效。              |
| 13   | `*6F`         | 校验和                                                              |

此外，还有`$GNGGA`（定位系统固定数据） 、`$GNGSV`（可见卫星详细） 、`$GNGSA`（DOP精度与活动卫星） 、`$GNVTG`（对地速度与航向） 、`$GNGLL` (地理坐标) 。本项目暂时用不到，不做展开。
