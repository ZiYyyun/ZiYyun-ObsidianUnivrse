

链表的一个节点：

```
struct Node
{
    int data;
    Node* next;
};
```

它实际上就是：
```
Node
┌──────────────┐
│ data         │
│ next ────────┼────→ 下一个 Node
└──────────────┘
```

例如：

```
head
 ↓
┌───────┬───────┐     ┌───────┬───────┐     ┌───────┬─────────┐
│  10   │  ─────┼────→│  20   │  ─────┼────→│  30   │ nullptr │
└───────┴───────┘     └───────┴───────┘     └───────┴─────────┘
```

这里最关键的一点：

> **10、20、30 不需要连续存在内存里。**

靠的是：

```
next
```

把它们串起来。
