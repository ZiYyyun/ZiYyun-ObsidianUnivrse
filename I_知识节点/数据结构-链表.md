



> [!QUESTION] 链表长什么样

链表的一个节点：
```
struct Node
{
    int data;
    Node* next;
};
```

它实际上就是：
```
Node
┌──────────────┐
│ data         │
│ next ────────┼────→ 下一个 Node
└──────────────┘
```

例如：

```
head
 ↓
┌───────┬───────┐     ┌───────┬───────┐     ┌───────┬─────────┐
│  10   │  ─────┼────→│  20   │  ─────┼────→│  30   │ nullptr │
└───────┴───────┘     └───────┴───────┘     └───────┴─────────┘
```

这里最关键的一点：

> **10、20、30 不需要连续存在内存里。**

靠的是：
```
next
```

把它们串起来。

### 链表的用法


```cpp
	Node node1, node2, node3;
	Node* head = &node1;  //[!DESCRIBE] 声明一个头节点，指向链表的第一个节点
	
	node1.data = 10;
	node1.next = &node2;

	node2.data = 20;
	node2.next = &node3;

	node3.data = 30;
	node3.next = nullptr;
```

那么逻辑上就是这样：
```
head
 ↓
node1          node2          node3
┌────┬─────┐  ┌────┬─────┐  ┌────┬─────────┐
│ 10 │  ───┼─→│ 20 │  ───┼─→│ 30 │ nullptr │
└────┴─────┘  └────┴─────┘  └────┴─────────┘
```
