## 基本定时器
### 时基单元

时基单元的的信号来源于从模式控制器或[[STM32-时钟树]]。
> [!NOTE] 运行逻辑
> ![[Pasted image 20260501182449.png]]
> 首先，从`RCC_`产生的时钟信号需要在`PSC`进行分频操作，当脉冲到达`CNT`计数器时，会被记录次数。当次数达到`ARR`所预设的次数时，计数器会被重新装载（即归零）。当重装载的次数达到`RCR`重复计数器的值时，触发`update`时间。


#### 控制寄存器1（CR1）
> 作用：配置工作模式

##### 自动重装载预装载使能 (ARPEN)
配置`ARR`寄存器是否具有缓冲

> [!NOTE] 重要！
> `ARPE` 是 **ARR 值的生效开关**
> - `ARPE=1`（开缓冲）：你改 ARR 的值，**下一个周期才生效**（不打乱当前定时，安全）
> - `ARPE=0`（关缓冲）：你改 ARR 的值，**立刻生效**（可能打断当前定时，不稳定）

##### 单脉冲模式（OPM）
发生更新时间后，是否停止计数器
##### 计数器使能（CEN）
开启或关闭计数器

#### 预分频寄存器（PSC）

> 作用：对输入进来的时钟信号进行分频

分频系数 = PSC的值 + 1


*例如：从时钟过来一个`10MHz`的信号，若我们需要`1MHz`的信号，则需要给`PSC`赋值为`9`。此时10/(9+1)=1MHz。*


#### 自动重装载寄存器（ARR）
> 作用：给定时器的计数器`CNT`设置**计数上限**。
- TIM6 是向上计数的：`CNT`从 0 开始，每来一个时钟脉冲就 + 1
 当`CNT`数到`ARR的值`时，会触发「更新事件」，然后`CNT`自动清零，重新从 0 开始计数
- 这个 “数到上限自动清零重数” 的过程，就是**自动重装载**的含义，是定时器循环定时的基础。



#### TIM6和TIM7计数器（CNT）
> 作用：记录脉冲的次数。


#### 中断使能寄存器（DIER）
##### 更新DMA请求使能
禁止或使能更新DMA请求


#### 状态寄存器（SR）
##### 更新中断标志（UIF）
当产生了更新中断后，硬件会将该寄存器置`1`

## 通用定时器
#### 捕获/比较寄存器（TIMx_CCR）

> [!NOTE] 主要结构
> **时基单元决定了PWM的周期，CCR寄存器决定占空比**
> ![[Pasted image 20260506172300.png]]
> CCR（捕获 / 比较寄存器）是 STM32 定时器每个通道（CH1~CH4）对应的 16 位寄存器，一端连接计数器 CNT，另一端同时接入输入捕获与输出比较模块，是定时器的双向核心节点。

`TIM_CCR`寄存器总共有4个，分别对应了上图四条通道。

操作方法：直接把要比较的值写入

#### 捕获/比较模式寄存器（TIMx_CCMR）


> [!NOTE] 注意
> 相较于`CCR`的四个寄存器，`CCMR`只有两个，这两个寄存器对应了四个通道模式控制，一拖二。
> ![[Pasted image 20260506190358.png]]
> 由图可见，从中间一分为二，右边控制1左边控制2.


其中：
- `CCxS`：用于配置通道x的**输入/输出**
- `OCxM`：用于配置通道x的8种**模式**，如下图

#### 捕获/比较使能寄存器(TIMx_CCER)
![[Pasted image 20260506192145.png]]
这个寄存器比较简单，
- `CCxE`：输入/捕获x输出**使能**
- `CCxP`：输入/捕获x输出**极性**
*极性：如果极性设置为0，则“有效电平”为高电平，反之则为低电平*

### 输出比较

| OCxM[2:0] | 模式名称                        | 中文       | 行为描述                                                                                     |
| --------- | --------------------------- | -------- | ---------------------------------------------------------------------------------------- |
| 000       | Frozen                      | 冻结       | CNT ≠ CCRx：输出不变；CNT=CCRx 时，OC 输出不改变。比较事件对输出无影响。                                          |
| 001       | Set active level on match   | 匹配时置 1   | CNT 计数等于 CCRx，OC 输出置为有效电平；其他时刻保持。                                                        |
| 010       | Clear active level on match | 匹配时清 0   | CNT 计数等于 CCRx，OC 输出置为无效电平；其他时刻保持。                                                        |
| 011       | Toggle on match             | 匹配翻转     | CNT 等于 CCRx，OC 输出电平翻转；适合输出方波。                                                            |
| 100       | Force inactive level        | 强制无效电平   | 强制 OC 输出无效电平，忽略计数器与 CCR 比较。                                                              |
| 101       | Force active level          | 强制有效电平   | 强制 OC 输出有效电平，忽略计数器与 CCR 比较。                                                              |
| 110       | PWM mode 1                  | PWM 模式 1 | **向上计数：CNT＜CCRx → OC 有效；CNT≥CCRx → OC 无效**<br><br>向下计数：CNT＞CCRx → OC 有效；CNT≤CCRx → OC 无效 |
| 111       | PWM mode 2                  | PWM 模式 2 | **向上计数：CNT＜CCRx → OC 无效；CNT≥CCRx → OC 有效**<br><br>向下计数：CNT＞CCRx → OC 无效；CNT≤CCRx → OC 有效 |
