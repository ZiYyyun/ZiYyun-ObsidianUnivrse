#理论/嵌入式/STM32 

直接存储器存取(DMA)用来提供在外设和存储器之间或者存储器和存储器之间的高速数据传
输。无须CPU干预，数据可以通过DMA快速地移动，这就节省了CPU的资源来做其他操作。
两个DMA控制器有12个通道(DMA1有7个通道，DMA2有5个通道)，每个通道专门用来管理来自于一个或多个外设对存储器访问的请求。还有一个仲裁器来协调各个DMA请求的优先权。

---

### 寄存器分类
```c
typedef struct
{
  __IO uint32_t CCR;
  __IO uint32_t CNDTR;
  __IO uint32_t CPAR;
  __IO uint32_t CMAR;
} DMA_Channel_TypeDef;
```
如结构体定义所示，这四个寄存器用于控制DMA

### 通道配置过程
1. 在DMA_CPARx寄存器中设置外设寄存器的地址。发生外设数据传输请求时，这个地址将
是数据传输的源或目标。
2. 在DMA_CMARx寄存器中设置数据存储器的地址。发生外设数据传输请求时，传输的数
据将从这个地址读出或写入这个地址。
3. 在DMA_CNDTRx寄存器中设置要传输的数据量。在每个数据传输后，这个数值递减。
4. 在DMA_CCRx寄存器的PL[1:0]位中设置通道的优先级。
5. 在DMA_CCRx寄存器中设置数据传输的方向、循环模式、外设和存储器的增量模式、外
设和存储器的数据宽度、传输一半产生中断或传输完成产生中断。
6. 设置DMA_CCRx寄存器的ENABLE位，启动该通道。
一旦启动了DMA通道，它既可响应连到该通道上的外设的DMA请求。


#### DMA通道x配置寄存器
##### `mem2mem`：Memory to Memory（存储器到存储器模式）
> DMA通道的操作可以在没有外设请求的情况下进行，这种操作就是存储器到存储器模式

- **全称**：Memory to Memory mode
- **核心功能**：让 DMA 在**两个存储器之间**（如 Flash→RAM、RAM→RAM）直接搬运数据，而不需要外设参与。
- **工作原理**：
    
    - 普通 DMA 传输是「外设↔存储器」，由外设的请求信号（如 USART 的 TXE、RXNE）触发。
    - 开启`mem2mem`后，DMA 变为「存储器↔存储器」，由软件直接置位控制位启动传输，无需外部触发。
- **典型应用**：开机时把 Flash 中的常量数组搬运到 RAM 中加速访问，或者快速复制一段内存数据。

---

##### `pl`：Priority Level（通道优先级）
![[16296a6acb1fee0cf7fc414afcc3d19b~tplv-be4g95zd3a-image.jpeg]]
- **全称**：Priority Level
- **核心功能**：当**多个 DMA 通道同时请求传输**时，决定哪个通道先执行，避免总线冲突。
- **优先级等级**（STM32 标准，共 4 级，从低到高）：
    
    - `Low`（低优先级）
    - `Medium`（中优先级）
    - `High`（高优先级）
    - `Very High`（非常高优先级）
    
- **仲裁规则**：
    
    1. 先看软件设置的`pl`等级，高优先级通道先传输。
    2. 若优先级相同，看通道编号（通道 0 > 通道 1 > 通道 2…），编号小的先传输。
    
- **典型应用**：把串口接收的 DMA 通道设为`Very High`，确保数据不丢失；把普通内存搬运设为`Low`，后台慢慢传。

---

#####  `msize`：Memory Size（存储器端数据宽度）

- **全称**：Memory Data Size
- **核心功能**：定义 DMA 在**存储器一侧**每次读写的数据位宽。
- **可选值**：
    
    - `Byte`（8 位，1 字节）
    - `Half Word`（16 位，半字）
    - `Word`（32 位，字）
    
- **关键要求**：必须和存储器的实际位宽匹配，否则可能出现数据对齐错误（比如访问 32 位 SRAM 时用`Byte`会慢，但用`Word`最快）。

---

##### `psize`：Peripheral Size（外设端数据宽度）

- **全称**：Peripheral Data Size
- **核心功能**：定义 DMA 在**外设一侧**每次读写的数据位宽。
- **可选值**：和`msize`完全一致（Byte/Half Word/Word）。
- **关键配合**：
    
    - 通常和`msize`设为相同值（比如 USART 是 8 位数据，`psize`和`msize`都设为`Byte`）。
    - 若设为不同值，DMA 会自动进行数据的「拆包 / 打包」（比如外设 16 位、存储器 32 位，DMA 会把两个 16 位拼成一个 32 位再存），但这种场景较少用。
 
---

### `minc`：Memory Increment（存储器地址自增）

- **全称**：Memory Increment mode
- **核心功能**：控制每次传输后，**存储器的地址指针是否自动向后移动**。
- **两种模式**：
    
    1. **使能`minc`（地址自增）**：
        
        - 每次传输完成，存储器地址自动 + `msize`（比如`msize=Word`，地址就 + 4）。
        - **典型应用**：传输数组、缓冲区等连续内存块（比如把串口收到的数据存到数组里，每存一个字节地址自动 + 1）。
        
    2. **禁用`minc`（地址固定）**：
        
        - 每次传输都访问存储器的**同一个固定地址**。
        - **典型应用**：外设的单个寄存器（比如把内存里的数据连续发到 USART 的 DR 寄存器，DR 地址固定，不需要自增）。
