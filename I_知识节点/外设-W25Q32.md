## 一、W25Q32 存储结构详解

W25Q32 是 32Mbit（4MB）的 SPI NOR Flash，它的存储单元从大到小分为 **Block（块）、Sector（扇区）、Page（页）** 三级结构：

表格

|单位|数量|大小|层级关系|
|:--|:--|:--|:--|
|**Block（块）**|64 个|64KB|1 块 = 16 个扇区|
|**Sector（扇区）**|1024 个|4KB|1 扇区 = 16 个页|
|**Page（页）**|16384 个|256 字节|1 页 = 256 字节|

---

### 1. 各单位的核心含义

- **Page（页）**：
    
    - 定义：W25Q32 **写入（编程）操作的最小单位**，每次页编程最多连续写入 256 字节。
    - 特点：Flash 的写入操作只能将位从 `1` 改为 `0`，因此写入前必须先擦除目标区域。
    
- **Sector（扇区）**：
    
    - 定义：W25Q32 **擦除操作的最小单位**，每次扇区擦除会将 4KB 数据全部置为 `0xFF`。
    - 特点：如果需要修改单个字节，也必须先擦除整个扇区，再重新写入所有数据，因此修改前通常需要备份扇区数据。
    
- **Block（块）**：
    
    - 定义：由 16 个扇区组成的更大单元，支持 64KB 块擦除，也支持部分型号的 32KB 半块擦除。
    - 特点：擦除速度比扇区擦除更快，适合批量擦除连续数据区域。

## 二、核心寄存器与操作指令

W25Q32 没有传统意义上的 “地址映射寄存器”，而是通过 **SPI 指令 + 状态寄存器** 实现所有操作，核心分为三类：

### 1. 状态寄存器（Status Register）

W25Q32 包含 2 个 8 位状态寄存器，其中关键位如下：

- **BUSY（bit0）**：只读位。芯片执行擦除 / 编程 / 写状态寄存器时自动置 1，操作完成后置 0。主机必须等待 BUSY=0 才能发送新指令。
- **WEL（bit1）**：写使能锁存位。执行 `Write Enable(0x06)` 后置 1，允许写入 / 擦除操作；执行 `Write Disable(0x04)` 或操作完成后自动清 0。
- **BP2/BP1/BP0（bit2~4）**：块保护位，用于设置写保护区域，防止意外擦除 / 写入。

### 2. 基础操作指令与流程

#### （1）读取数据（Read）

- 指令：`0x03`（标准读）/ `0x0B`（快速读）
- 流程：
    
    1. 拉低片选 CS
    2. 发送指令 `0x03`
    3. 发送 24 位地址（A23~A0）
    4. 连续读取数据（长度任意，不受页 / 扇区限制）
    5. 拉高片选 CS
    

#### （2）页编程（Page Program）

- 指令：`0x02`
- 流程：
    
    1. 发送 `Write Enable(0x06)`，使 WEL=1
    2. 拉低片选 CS
    3. 发送指令 `0x02`
    4. 发送 24 位起始地址
    5. 连续写入最多 256 字节数据（不能跨页）
    6. 拉高片选 CS
    7. 循环读取状态寄存器，等待 BUSY=0，确认操作完成
    

#### （3）扇区擦除（Sector Erase）

- 指令：`0x20`
- 流程：
    
    1. 发送 `Write Enable(0x06)`，使 WEL=1
    2. 拉低片选 CS
    3. 发送指令 `0x20`
    4. 发送 24 位地址（只要落在目标扇区内即可）
    5. 拉高片选 CS
    6. 循环读取状态寄存器，等待 BUSY=0，确认擦除完成
    

#### （4）块擦除（Block Erase）

- 指令：`0xD8`（64KB 块擦除）/ `0x52`（32KB 半块擦除）
- 流程与扇区擦除一致，仅指令码不同，擦除范围更大。

#### （5）整片擦除（Chip Erase）

- 指令：`0xC7` / `0x60`
- 会擦除整个 4MB Flash，所有位恢复为 `0xFF`，耗时较长（约 10~100 秒，取决于型号）。

## 三、关键操作注意事项

1. **必须先擦除再写入**：Flash 写入只能将 `1` 改为 `0`，无法直接将 `0` 改回 `1`，因此修改数据前必须先擦除对应扇区 / 块。
2. **页编程不能跨页**：一次 `0x02` 指令最多写入 256 字节，且地址不能跨页，跨页写入会导致数据覆盖。
3. **必须等待 BUSY 位空闲**：擦除 / 编程操作期间芯片会忽略除读状态寄存器外的所有指令，必须等待操作完成。
4. **写保护位影响**：如果状态寄存器的 BP2/BP1/BP0 位设置了保护区域，擦除 / 写入操作会被拒绝，需先修改保护位。
