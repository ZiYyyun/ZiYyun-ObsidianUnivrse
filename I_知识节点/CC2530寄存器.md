## 定时寄存器
### T1CTL（定时器1）

| 位位置 | 位名称  | 描述                  |
| --- | ---- | ------------------- |
| 7-5 | -    | 保留位，未使用。            |
| 2-3 | DIV  | 分频选择位。控制定时器1的时钟分频比。 |
| 0-1 | MODE | 定时器1的工作模式选择位。       |

- #### DIV (位2-3) - 分频选择位
    
	- `00`：不分频（16 MHz）
    - `01`：8 分频
    - `10`：32 分频
    - `11`：128 分频

- #### MODE (位0-1) - 定时器1的工作模式
    
    - `00`：停止模式，定时器不运行
    - `01`：自由运行模式，定时器从0计数到最大值（0xFFFF），然后自动重装为0
    - `10`：模，从0x0000到T1CC0反计数
    - `11`：正计数/倒计数，从0x0000到T1CC0反复计数并且从T1CCO倒计数到0x000


### T3CTL（定时器3）

| 位位置 | 位名称       | 描述    |
| --- | --------- | ----- |
| 5-7 | DIV[1:0]  | 分频选择位 |
| 4   | START     | 启止控制位 |
| 3   | OVFIM     | 溢出中断  |
| 2   | CLR       | 清零位   |
| 0-1 | MODE[1:0] | 模式选择  |


- #### MODE (位0-1) - 工作模式选择
	
	- `00`：自动重装模式，定时器从指定值降到0后，自动重装并继续计数
	- `01`：降序计数模式，定时器从指定值降到0
	- `10`：模计数（反复从 0X00到T3CC0 计数)
	- `11`：UP/DOWN(反复从0X00到T3CC0 计数再到0X00)

- ####  OVFIM (位2) - 清零位
	
	- `0`：无操作
	- `1`：写1时，定时器计数器清零

- #### CLR (位3) - 溢出中断掩码
	
	- `0`：禁用溢出中断
	- `1`：使能溢出中断，当定时器计数器溢出时产生中断

#### START (位4) - 启止控制位
	
 	- `0`：停止定时器
  	- `1`：启动定时器

- ####  DIV (位5-7) - 分频选择
    
    - `000`：不分频，输入时钟为16 MHz（默认时钟频率）
    - `001`：2 分频
    - `010`：4 分频
    - `011`：8 分频
    - `100`：16分频
    - `101`：32分频
    - `110`：64分频
    - `111`：128分频
