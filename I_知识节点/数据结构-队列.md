
```
Node
├── data
└── next

front（队头，出队）                     rear（队尾，入队）
   ↓                                      ↓
[10 | next] → [20 | next] → [30 | nullptr]
  队头            中间            队尾
```



### 基本操作
#### 初始化

> Queue::Queue()
```cpp
	rear = front = nullptr;
	size = 0;
```

#### 入列
> void Queue::enqueue(int value)
```cpp
	Node* node = new Node;
	node->data = value;
	node->next = nullptr;

	if (size == 0)
	{
		front = rear = node;
	}
	else
	{
		rear->next = node;
		rear = node;
	}
	size++;
```


#### 出列
> void Queue::dequeue()
```cpp
	//队列出列是从front出
	Node* node = front;
	front = front->next;
	delete node;

	size--;
```
