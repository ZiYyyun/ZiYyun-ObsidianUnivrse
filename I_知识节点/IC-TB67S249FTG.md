#IC 
TB67S249FTG是日本东芝(Toshiba)推出的一款**双极性步进电机驱动芯片**
STM32不能直接驱动步进电机，因为它只能输出3.3V、mA级别的电流，根本带不动。所以TB67S249FTG相当于一个**功率放大器**

---

### 芯片概述
TB67S249FTG内部集成了两个全桥（H桥）

```
      A+
       |
     H桥
       |
      A-

      B+
       |
     H桥
       |
      B-
```





### 引脚定义

### 关键引脚功能
| 引脚名          | 功能说明                       | 原理图中的应用                                       |
| ------------ | -------------------------- | --------------------------------------------- |
| `CLK`        | 步进脉冲输入，上升沿触发一次步进           | 原理图中接了上拉电阻`R107`，外部脉冲输入，频率决定电机转速              |
| `CW/CCW`     | 电机转向控制：高电平 = 顺时针，低电平 = 逆时针 | 接`DIR`信号，控制电机正反转                              |
| `ENABLE`     | 驱动使能：低电平使能，高电平关断输出         | 接外部控制信号，低电平时芯片工作，高电平时输出关闭                     |
| `RESET`      | 芯片复位：低电平复位，高电平正常工作         | 原理图中接了上拉电阻`R83`，上电时自动完成复位                     |
| `DMODE0/1/2` | 微步细分设置引脚，3 位组合设置细分模式       | 原理图中接了拨码开关`SW1/SW2/SW3`，可设置 1/2/4/8/16/32 等细分 |
| `MO`         | 电机位置检测输出：低电平表示处于初始电角度位置    | 开漏输出，可用于回零检测，原理图中保留该引脚                        |
