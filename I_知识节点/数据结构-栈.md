

> [!NOTE] 概述
>   栈是一种只允许在同一端进行插入和删除的线性结构，这一端叫栈顶，另一端叫栈底；新元素只能压入栈顶（push），取出时也只能从栈顶弹出（pop），查看栈顶则用 peek/top，因此它遵循“后进先出”（LIFO）的规则——最后放进去的元素最先被取出，就像一摞盘子，你只能从最上面放、也只能从最上面拿；正因如此，它天然适合处理函数调用、表达式求值、括号匹配、撤销操作和深度优先搜索等需要“回到最近状态”的场景。

```
top
 ↓
┌────────────────┐
│ data: 30       │  ← 栈顶
│ next: ↓        │
└────────────────┘
        ↓
┌────────────────┐
│ data: 20       │
│ next: ↓        │
└────────────────┘
        ↓
┌────────────────┐
│ data: 10       │  ← 栈底
│ next: nullptr  │
└────────────────┘
```

其实栈(Stack)就是一个立起来的链表(LinkList)，
等同于这样：
```
Node
├── data
└── next

top
 ↓
[30 | next] → [20 | next] → [10 | nullptr]
 栈顶                        栈底
```

### 初始化

#### push压栈

```cpp
void Stack::push(int value)
{
	//创建一个新Node
	Node* node = new Node;
	node->data = value;
	node->next = top;
	top = node;

	size++;
}
```


#### pop出栈

```cpp
void Stack::pop()
{
	if (top == nullptr) return;

	Node* temp = top;
	top = top->next;
	delete temp;
	size--;
}
```
