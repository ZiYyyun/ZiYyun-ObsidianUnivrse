#理论/嵌入式/STM32 



### 核心定义
```c stm32f103x8.h
typedef struct
{
  __IO uint32_t CRL;
  __IO uint32_t CRH;
  __IO uint32_t IDR;
  __IO uint32_t ODR;
  __IO uint32_t BSRR;
  __IO uint32_t BRR;
  __IO uint32_t LCKR;
} GPIO_TypeDef;
```

| 寄存器      | 功能                        |
| -------- | ------------------------- |
| **CRL**  | ==配置==`Px0`到`Px7`引脚（低八位）  |
| **CRH**  | ==配置==`Px8`到`Px15`引脚（高八位） |
| **IDR**  | ==判断==引脚的输入电平（`0`/`1`）    |
| **ODR**  | ==控制==引脚的输出电平（`0`/`1`）    |
| **BSRR** | ==设置==或==清除==引脚电平         |
| **BRR**  | ==清除==或==复位==引脚           |
| **LCKR** | ==锁定==引脚配置                |

### 端口配置低寄存器(GPIOx_CRL)

> [!NOTE] CRL
> **CRL** (Configuration Register Low) 寄存器用于配置端口中**低 8 个引脚**（即 `Px0` 到 `Px7`，如 `PA0` 到 `PA7` 或 `PB0` 到 `PB7`）。
> - 每个引脚使用 4 位来配置，因此这个寄存器包含了 32 位，每 4 位对应一个引脚。
> - **前 2 位**用于设置该引脚的工作模式（输入/输出及速度）；
> - **后 2 位**用于设置引脚的类型（推挽/开漏）和输入类型（上拉/下拉/模拟等）。

### 端口输入数据寄存器（GPIOx_IDR）

> [!NOTE] IDR
> **IDR**（Input Data Register）是用于读取引脚电平状态的寄存器。它提供了 GPIO 端口所有引脚当前的输入状态。
- 每个引脚对应 **IDR** 的一位。
- 如果某个位是 `1`，表示引脚为高电平；
- 如果某个位是 `0`，表示引脚为低电平。

```c
if (GPIOB->IDR & (1 << 0)) {
    // 如果 **IDR** 的第 0 位是 `1`，表示引脚输入为高电平
}
```
### 端口输出寄存器（GPIOx_ODR）

> [!NOTE] ODR
> **ODR**（Output Data Register）是用于控制引脚输出电平的寄存器。

- 每个引脚对应 **ODR** 的一位。
- 如果某个位被设置为 `1`，对应引脚输出高电平；
- 如果某个位被设置为 `0`，对应引脚输出低电平。
```c
GPIOB->ODR |= (1 << 0);  // 将 PB0 引脚输出高电平
GPIOB->ODR &= ~(1 << 0); // 将 PB0 引脚输出低电平
```
### GPIO 端口位设置/清除寄存器 (BSRR)

> [!NOTE] BSRR
> **BSRR**（Bit Set and Reset Register）是位设置和复位寄存器，用于**原子性地设置或清除 `GPIO` 引脚**。这是一个 32 位寄存器，低 16 位用于**设置引脚为高电平**，高 16 位用于**清除引脚为低电平**。这个寄存器操作可以避免传统方式可能导致的竞态条件。
> ![[Pasted image 20240913214153.png]]

- **设置某个引脚为高电平**：写入低 16 位（对应 GPIO 端口的引脚）。
- **设置某个引脚为低电平**：写入高 16 位（对应 GPIO 端口的引脚）。
```c
GPIOA->BSRR = (1 << 9);       //设置PA9为高电平
GPIOA->BSRR = (1 << (9+16));  //设置PA9为低电平
```

### GPIO 端口位复位寄存器 (BRR)

> [!NOTE] BRR
> **BRR**（Bit Reset Register）是位复位寄存器，它用于**清除（复位）GPIO 引脚**，即将引脚输出设置为低电平。每个引脚对应 BRR 寄存器的一位，当写入 `1` 时，清除对应引脚的输出（置低电平）。
> **快速清除 GPIO 状态**：可以在不影响其他引脚状态的情况下清除某个引脚的电平。
> ![[Pasted image 20240913214134.png]]

```c
GPIOA->BRR = (1 << 9);  // 将 PA9 引脚设置为低电平
```
**注意：** STM32F1 系列中 BRR 是 16 位寄存器，而其他 STM32 系列可能使用 BSRR 来代替 BRR。

### GPIO 端口配置锁定寄存器 (LCKR)

> [!NOTE] LCKR
> **LCKR**（Lock Register）是 GPIO 配置锁定寄存器，它允许你将某个 GPIO 引脚的配置进行**锁定**，一旦锁定后，该引脚的配置不能被修改，直到下一次系统复位。这对一些安全关键应用非常重要，防止配置被意外更改。
> ![[Pasted image 20240913214223.png]]

要锁定一个引脚的配置，需要执行一个特定的**锁定顺序**：
1. 写入 `1` 到 `LCKK` 位，开始锁定过程。
2. 写入 `1` 到要锁定的引脚对应的 `LCKx` 位（如 `LCK9`）。
3. 再次写入 `1` 到 `LCKK` 位确认。
4. 读取 `LCKK` 位来完成锁定。

```c
GPIOA->LCKR |= (1 << 9);      // 锁定 PA9 配置
GPIOA->LCKR |= (1 << 16);     // 启用锁定
if (GPIOA->LCKR & (1 << 16))  // 读取锁定状态，确认锁定生效
{
    // PA9 的配置已经被锁定
}
```
