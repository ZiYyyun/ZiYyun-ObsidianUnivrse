#实操/开发/嵌入式/STM32

### 配置APB2ENR
> 由[[STM32存储器和总线架构#系统构架]]可知，GPIO被桥接在APB2桥，故预想启用GPIO应从APB2ENR寄存器入手

```c
*(uint32_t *)( 0x40021000 + 0x18 ) = 0x00000004;
```
 其中，由 [[STM32-寄存器地址映射表]] 可知， `0x40021000`为[[STM32-RCC寄存器]]组的起始地址，加上其偏移位`0x18`得到实际地址。
 我们需要操作的GPIOA在其位2，故我们需要把它赋值为1开启。
 另外，由于`0x40021000 + 0x18`为指针变量，我们需要把它强转为`uint32_t`类型，最前面的星号来实现**解引用**

后者同上。
### 配置GPIOx_CRL

```c
*(uint32_t *)( 0x40010800 + 0x00) = 3;
```
### 配置GPIOx_ODR

```c
*(uint32_t *)( 0x40010800 + 0x0c) = 0x111110;
```
