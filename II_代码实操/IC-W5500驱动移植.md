## 🔧 一、硬件抽象层（**必须修改**）

> **文件**：`wizchip_conf.c` + `wizchip_conf.h`  
> **作用**：连接 W5500 芯片与你的单片机硬件（**关键修改点！**）
### ✅ `wizchip_conf.h`（配置头文件）
```c
// 需要你修改的部分（根据你的硬件平台）：
define _WIZCHIP_          5500    // 指定芯片型号（W5500）
// 定义硬件接口引脚（重点！）
define WIZCHIP_CSPIN     GPIO_PIN_4    // 片选引脚 (CS)
define WIZCHIP_RSTPIN    GPIO_PIN_5    // 复位引脚 (RST)
define WIZCHIP_INTPIN    GPIO_PIN_6    // 中断引脚 (INT)
// 声明硬件接口函数（你必须实现这些函数）
void wizchip_init(void);
void wizchip_select(void);
void wizchip_deselect(void);
void wizchip_reset(void);
uint8_t wizchip_read_byte(uint32_t addr);
void wizchip_write_byte(uint32_t addr, uint8_t data);
```

### ✅ `wizchip_conf.c`（硬件接口实现）
```c
void wizchip_select(void) { 
	HAL_GPIO_WritePin(WIZCHIP_CS_PORT, WIZCHIP_CSPIN, GPIO_PIN_RESET); 
} 

void wizchip_deselect(void) {  
	HAL_GPIO_WritePin(WIZCHIP_CS_PORT, WIZCHIP_CSPIN, GPIO_PIN_SET);
}

uint8_t wizchip_spi_readbyte(void)
{
   uint8_t rb = 0;
   HAL_SPI_Receive(&hspi2, &rb, 1, 1000);
   return rb;
}

void wizchip_spi_writebyte(uint8_t wb)
{
   HAL_SPI_Transmit(&hspi2, &wb, 1, 1000);
	}
} 

void wizchip_reset(void) {
	HAL_GPIO_WritePin(WIZCHIP_RST_PORT, WIZCHIP_RSTPIN, GPIO_PIN_RESET);HAL_Delay(10);
	HAL_GPIO_WritePin(WIZCHIP_RST_PORT, WIZCHIP_RSTPIN, GPIO_PIN_SET); 
}
```
只需把对应的操作写入就好，具体引脚视情况而定

> ⚠️ **关键提示**：  
> **这是唯一需要你修改的文件**！其他文件都不要动。  
> **修改重点**：
> 
> 1. 填写正确的 **GPIO 引脚定义**（匹配你的电路板）
> 2. 用你的单片机 **SPI 驱动** 替换 `wizchip_read_byte`/`write_byte`
> 3. 用 **GPIO 控制** 替换 `select`/`deselect`/`reset` 函数

## 🌐 二、芯片驱动层（**无需修改**）

> **文件**：`w5500.c` + `w5500.h`  
> **作用**：实现 W5500 芯片的寄存器操作和 TCP/IP 协议栈

### ✅ `w5500.h`（芯片接口声明）
```c
// 你直接调用的 API 函数（无需修改）：
void w5500_init(uint8_t* mac);       // 初始化 W5500
void w5500_set_ip(uint8_t* ip);      // 设置 IP 地址
void w5500_set_gateway(uint8_t* gw); // 设置网关
void w5500_set_subnet(uint8_t* sn);  // 设置子网掩码
// TCP/UDP 操作函数（你直接调用）：
void w5500_tcp_connect(uint8_t* ip, uint16_t port);
void w5500_tcp_send(uint8_t* data, uint16_t len);
uint16_t w5500_tcp_recv(uint8_t* buf);
```

### ✅ `w5500.c`（芯片驱动实现）

- **核心功能**：  
    • W5500 寄存器配置（MR, GAR, SUBR 等）  
    • TCP 三次握手实现  
    • UDP 数据包封装  
    • 中断状态处理
- **重要提示**：  
    **绝对不要修改这个文件**！这是 WIZnet 官方验证过的稳定代码，负责与 W5500 芯片直接通信。
