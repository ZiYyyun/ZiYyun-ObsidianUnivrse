### 初始化
```c Dri_1wire_Init()
bit Dri_1wrie_Init()

{

    bit result;
    //主设备发送复位脉冲
    DQ = 0;
    Delay60us();
    DQ = 1;
  
    //18B20回复主设备
    Delay60us(1);

    result = ~DQ; 

    Delay60us();

    return result;
}
```

> 注意：因为1wire采用推挽输出，所以默认情况下DQ为高电平，我们第一次给DQ赋值拉低是为了给从设备发送初始化脉冲，这个脉冲的时间只需要15-60us，所以过了这个时间我们还需要吧DQ给拉回去，即赋值1。这样我们的工作就做完了，正常情况下，从设备会在60-240us之内完成响应。如何响应呢？它会给DQ回一个高电平，这就是我们判断的标准。
> 所以理一下：如果最后DQ为1，即从设备正常响应，反之则错误
> 故result取DQ的反值
