#### 对寄存器的某些位清零且不影响其他位

> [!示例]
>    寄存器P1TM的当前值是0x6c，现需要将该寄存器的第**1**位、第**3** 位和第**5**位设置为**0**，同时不能影响该寄存器其他位的值，那么，在C语言中应该怎么编写代码呢？

   使用“**&=**”将寄存器指定位清0，同时不影响其他位的值。

```c
P1TM &=~ 0x2A；
```

>    **与**的操作特点是，该位有0结果就为0，若为1则保存原来值不变。

   首先将字节 **0000 0000** 中**要操作的位**设置为**1**，即**0010 1010**，在将该数值**取反**，即**1101 0101**，也就是**~0x2A**。再将该值与寄存器P1TM“相与”，那么有0的位，即1、3、5位将被清0，其余的位会保持原来的值不变。

   所以：P1TM的当前值为0x6c，即0110 1100，

   **0110 1100** **&&** **1101 0101** = **0100 0100**，即1、3、5位清0，其他位不变。

该方法只能操作多位同时清0，或者某一位清0的情况，如果要将寄存器的位既要清0又要置1，则不能采用这种写法。（其中原因自己思考一下）

```c
//在不少嵌入式应用的源码程序中，对于寄存器的第n位的清0操作也可以写成：
寄存器 &= ~(0x01<<(n))；
```

#### 对寄存器的某些位置1且不影响其他位

> [!示例]
> 寄存器P1TM的当前值是0x6c，现需要将该寄存器的第**1**位、第**4**位和第**5**位设置为**1**，同时不能影响该寄存器其他位的值，那么，在C语言中应该怎么编写代码呢？
 
 使用“**|=**”将寄存器指定位置1，同时不影响其他位的值。
```c
P1TM |= 0x32；
```

> **或**的操作的特点是，该位有1结果就为1，若为0则保存原来值不变。

```c
//对于寄存器的第n位的清0操作也可以写成：
寄存器 |= (0x01<<(n))；
```


### 整数提升(Integter Promotion)
有一个典型问题：为什么 `uint8_t << 8` 不会变成 0？

> 参与表达式运算之前，凡是比 `int` 小的整数类型，都会先提升（Promote）成 `int`（或 `unsigned int`）。

假设：
```c
uint8_t a = 0x12;
uint16_t b = a << 8;
```
这里的a其实不会消失，其实编译器会把它提升，即：
```c
int（假设32位）
00000000 00000000 00000000 00010010
```
左移之后：
```c
00000000 00000000 00010010 00000000
```
然后再进行复制，变量`b`即可正常接收


> [!NOTE] 总结
> 在 C 语言中，`char`、`uint8_t`、`short` 等小于 `int` 的整数类型，在参与算术、位运算时都会先自动进行"整数提升（Integer Promotion）"，再执行运算，因此 `uint8_t << 8` 并不会先丢失数据；真正的数据截断发生在结果重新赋值给较小类型时。
