1结构体：把不同类型的数据打包

对应课本补充：结构体的定义
结构体 = 自己造的一种新数据类型，把不同类型的数据打包成一个整体。 类比：一张「学生登记表」，学号是 int、姓名是一串字符、性别是 char、年龄是 int，四样东西属于同一个人，用结构体把它们装进一个袋子里。

📐 语法形式


    

      struct 结构体标识符 { 成员变量列表; };
    

    

      花括号 {} 里面用分号隔开的变量叫成员变量，每一个描述这个事物的一个方面。
      成员可以是基本类型（int / float / char）、数组、指针，甚至另一个结构体。

顺序表 = 一块连续空间的首地址 elem + 当前长度 length。注意：成员又是另一个结构体类型。

3数组、静态分配与动态分配

  
对应课本补充：数组定义、malloc/free、new/delete


  

    静态分配 = 一开始就定死大小；动态分配 = 先拿个指针，用多少再申请多少。
    类比：静态像提前包好 100 间房，不管住不住都占着；动态像先拿一把钥匙（指针），来多少客人再开多少间房。

      L.data = (ElemType*)malloc(sizeof(ElemType)*MaxSize);
      真正要到一块连续空间之后才能往里放东西。
    

  


  

    
🛠 C 语言的三个内存函数（记住头文件 <stdlib.h>）

    

      
函数作用

      
malloc(m)开辟 m 个字节长度的空间，返回这段空间的首地址

      
sizeof(x)计算变量或类型 x 占多少字节

      
free(p)释放指针 p 所指的空间，彻底删除这块内存

    

    
💡 为什么总看见 sizeof(ElemType)*MaxSize？
    因为 malloc 只认「字节数」。要放 100 个 ElemType，就得先算 1 个 ElemType 多少字节，再乘 100。

4参数传递：整份补充里最容易晕的地方

  
对应课本补充：C++ 中的参数传递、传值 / 传地址


  

    想在函数里改掉外面的变量，就必须传地址（指针、数组名、引用）；只传值，改的永远是复印件。
    类比：传值 = 把证件的复印件给你，你在复印件上怎么涂改，原件纹丝不动；传地址 = 告诉你原件在哪个抽屉，你打开抽屉改的就是原件。
  


  

    
🗺 四种方式一张表

    

      
方式形参写法实参写法能改掉实参吗

      
传值float mswap(a,b)❌ 不能

      
传地址：指针float *mswap(&a,&b)✅ 能（要写 *m）

      
传地址：数组名int b[]sub(a)✅ 能

      
传地址：引用float &mswap(a,b)✅ 能（最省事）

    

    
实参和形参必须做到三个一致：类型一致、个数一致、顺序一致。

⚠️ 最容易踩的坑：指针版写错了

    

      

        
✅ 正确：交换指针指向的值

        

      

      

        
❌ 错误：只交换了指针本身

        

      

    

    
为什么错版改不动？
    因为 m、n 本身也是 main 传过来的复印件。
    在函数里把 m 改成指向 b、n 改成指向 a，只是把这两份复印件改了，main 里的 a、b 一个字节都没动。
    要改就必须写 *m、*n，顺着地址去动真正的那个值。

  


  

    
📚 什么是引用？为什么教材爱用它

    

    

      引用就是给一个对象起的另一个名字。int &j = i; 之后，j 和 i 是同一块内存，
      i 变了 j 就变，输出 i=7 j=7。
    

    

      引用作形参的三点好处：

      ① 和指针效果一样，形参变实参也变；

      ② 不会产生实参的副本，直接对实参操作，数据量大时省时间省空间；

      ③ 不用到处写 *指针名，也不用写成 &a，代码更好读。

5顺序表：把上面这些全用起来

  
对应课本：2.4 线性表的顺序表示与实现
