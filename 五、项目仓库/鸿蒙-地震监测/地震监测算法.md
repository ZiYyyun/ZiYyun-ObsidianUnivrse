

### 关键参数

| 参数         | 含义            |
| ---------- | ------------- |
| TRIGGER_MG | 触发阈值 180mg    |
| CLEAR_MG   | 清除阈值 80mg     |
| CONFIRM_MS | 确认时间 50ms     |
| CLEAR_MS   | 恢复时间 3000ms   |
| ARM_MS     | 启动预热时间 1000ms |

### 设计特性（采样层）
#### 迟滞（Hystersis）
- 触发阈值是`180mg`
- 恢复阈值是`80mg`
> 如果阈值只有一个，那么数据就会在阈值附近反复变化，导致警报一直不断被触发

设计两个不同阈值，用于提升系统稳定性
#### 时间确认

> 一检测到超过`180mg`就报警？NO！

因为触发原因有可能是：
- 人走过设备。
- 汽车经过。
- 设备受到一次碰撞。
- 传感器出现短暂噪声。

因此，程序还设置了持续时间要求。

> 不要仅仅根据某一个瞬间的数据作出判断，还要考虑数据随时间的变化。


> [!NOTE] STA/LTA 的基本思想
> STA/LTA 的基本思想是：
> 比较**短时间窗口**与**长时间窗口**的振动能量，判断当前振动是否==明显高于背景振动==。

#### 预热机制

假设设备刚刚启动：
- 传感器可能还没有稳定。
- 设备可能正在被人拿起、摆放。
- 初始姿态可能还在变化。

所以我们做了优化：
> 启动后先积累一段有效数据，达到预热条件后才允许进入地震判定。

```c
if (tilt_cal.ready) {
    sample.valid_fields |= EARTHQUAKE_SAMPLE_TILT;

    if (warmup >= EARTHQUAKE_SAMPLE_HZ * EARTHQUAKE_ARM_MS / 1000) {
        sample.event_state =
            GW_EARTHQUAKE_ALGORITHM_ENABLED ?
            (uint8_t)earthquake_judgement_update(
                &judgement, sample.acceleration_mg) :
            EARTHQUAKE_STATE_NORMAL;

        sample.valid_fields |= EARTHQUAKE_SAMPLE_EVENT;
    }
}
```


必须同时满足两个门槛：
1. `tilt_cal.ready`：倾斜校准完成
2. `warmup` 达到 100：有效采样预热完成
才会调用真正的振动判定算法。

这是一种典型的**算法使能条件**（Algorithm Arming Condition）


### 设计特性（算法层）


> [!NOTE] Title
> 这套算法本质上是一个基于三轴加速度的、多条件联合判定算法。它融合了动态加速度检测、重力分量滤除、STA/LTA、特征函数和状态机。


#### 重力的估量

> 一阶低通滤波
```c
j->gravity_mg[i] += delta / 64;
```

当前测量值 A 不断变化，但是我们不希望重力估计值跟着每一次快速振动剧烈变化。

所以每次只吸收当前误差的 1/64。

##### （核心）触发判定条件

|条件|实际含义|默认要求|
|---|---|---|
|amplitude_ok|动态加速度幅度足够大|180mg 或自适应阈值|
|ratio_ok|短期振动明显高于长期振动|1.8 倍|
|cf_ok|短期特征函数明显高于长期特征函数|1.5 倍|

必须三个条件同时满足：

$$
Trigger=Amplitude\land Ratio(STA/LTA)\land CF
$$
触发逻辑：

$$
\begin{aligned}
d_n &= \big|\,\|\mathbf a_n\|-1000\,\big|, \quad \|\mathbf a_n\| = \text{isqrt}\big(a_{x,n}^2+a_{y,n}^2+a_{z,n}^2\big) \\
g_{i,n} &= g_{i,n-1} + \left\lfloor\frac{a_{i,n}-g_{i,n-1}}{64}\right\rfloor, \quad v_n = \text{isqrt}\Big(\sum_{i\in\{x,y,z\}}(a_{i,n}-g_{i,n})^2\Big) \\
c_n &= v_n^2 + (\Delta v_n)^2, \quad \Delta v_n = |v_n-v_{n-1}| \\
\rho^{v}_n &= \frac{\bar v^{\text{sta}}_n}{\bar v^{\text{lta}}_n}, \quad \rho^{c}_n = \frac{c^{\text{sta}}_n}{c^{\text{lta}}_n}, \quad \tau^{A}_n = \max\!\big(180,\ \mu_n+6\sigma_n\big) \\
\text{Trigger}_n &= \underbrace{(d_n\ge\tau^{A}_n)}_{A_n} \;\land\; \underbrace{(\rho^{v}_n\ge1.80)}_{R_n} \;\land\; \underbrace{(\rho^{c}_n\ge1.50)}_{C_n} \\
\end{aligned}
$$
