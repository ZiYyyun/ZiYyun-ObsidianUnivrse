### 位置

> [!NOTE] 为什么要有编码器
> 如果不使用编码器，那么CPU将会面临：
   A相中断
   B相中断
   软件判断方向
   软件计数
   有了编码器之后：
	   CNT就能代表位置

> 位置的计算公式
$$
\theta=\frac{CNT}{N}\times360°
$$

%% 这里的N代表电机一圈所需的脉冲数 %%


### 速度

如何计算速度
电机转速（单位：**RPM**，转/分钟）的计算公式为：  
$$
n = \frac{60 \times \Delta \text{CNT}}{P \times T_s}​
$$
%% 60 ✖️ 编码器的差值 ➗️ 脉冲数✖️采集时间 %%

> 比如：

时刻1：
```
CNT = 1000
```
50ms后：
```
CNT = 1200
```
那么：
```
ΔCNT = 200
```
说明：
```
50ms走了200个计数
```
