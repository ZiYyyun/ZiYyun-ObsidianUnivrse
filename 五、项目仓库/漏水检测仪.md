



### 芯片引脚链接情况


| 引脚   | 功能      | 描述                |
| ---- | ------- | ----------------- |
| PA1  | ADC0    | SGM58031XMS10G/TR |
| PA2  | ADC1    | SGM58031XMS10G/TR |
|      |         |                   |
| PA9  | UART_TX |                   |
| PA10 | UART_RX |                   |


|芯片|干什么|比喻|
|---|---|---|
|**74HC4066**|接通/断开一条线路|**继电器**|
|**HEF4052**|多选一，把某一路接出来|**选择开关（旋钮）**|
