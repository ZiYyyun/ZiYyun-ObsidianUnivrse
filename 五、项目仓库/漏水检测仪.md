



### 芯片引脚链接情况


| 引脚   | 功能      | 描述                |
| ---- | ------- | ----------------- |
| PA1  | ADC0    | SGM58031XMS10G/TR |
| PA2  | ADC1    | SGM58031XMS10G/TR |
|      |         |                   |
| PA9  | UART_TX |                   |
| PA10 | UART_RX |                   |


|芯片|干什么|比喻|
|---|---|---|
|**74HC4066**|接通/断开一条线路|**继电器**|
|**HEF4052**|多选一，把某一路接出来|**选择开关（旋钮）**|

> 74HC4066负责"组成测量回路"，HEF4052负责"选择要测哪根线"，SGM58031负责"把电压变成数字"，GD32负责"调度所有芯片并计算漏水位置"。

### 4052
### 第一层：4052到底干什么？
它就是一个：

> 四选一模拟开关。
例如：
```
BLACK
GREEN
YELLOW
RED
```
四根线。
ADC只有两个输入：
```
AIN0
AIN1
```
怎么办？
所以4052负责：
```
AIN0 ← 任意选一根线

AIN1 ← 任意选另一根线
```

### 第二层：4066到底负责什么？





看看4066。

```
1Y ---> RED

2Y ---> YELLOW

3Y ---> GREEN

4Y ---> BLACK
```

而另一端：

```
1Z ---- +3.3

2Z ---- R16 ---- +3.3

3Z ---- GND

4Z ---- GND
```

然后：

```
PB4

PB3

PA15

PB5
```

控制四个MOS开关。

什么意思？

例如：

打开1E。

其实就是：

```
RED
│
│
4066
│
│
+3.3
```

导通。
