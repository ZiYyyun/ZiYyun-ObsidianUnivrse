
### 项目架构
```
				┌──────────────────────────────-┐
				│        Application            │
				│  GPIO / MQTT / LLM / UI       │
				└──────────────▲───────────────-┘
				               │
				┌──────────────┴───────────────-┐
				│      Speech Engine            │
				│  ESP-SR (AFE/WakeNet/VAD)     │
				└──────────────▲───────────────-┘
				               │
				┌──────────────┴───────────────-┐
```

### 工程目录

| 文件                  | 职责                                | 对应 ESP 官方组件                         |
| ------------------- | --------------------------------- | ----------------------------------- |
| `xiaozhi_audio`     | 管理 ES8311、I2S、PCM 输入输出            | `esp_codec_dev` + `esp_audio_codec` |
| `xiaozhi_sr`        | AFE、VAD、WakeNet、MultiNet，完成本地语音处理 | `esp-sr`                            |
| `xiaozhi_encoder`   | PCM → Opus（或其他编码），为网络传输准备数据       | 编码库（不属于 `esp-sr`）                   |
| `app_main`（或其他业务模块） | 初始化各模块、联网、控制设备、与服务器交互             | 用户自己的应用逻辑                           |


### 声学框架

| 功能           | 实现方式                    | 说明                                         |
| ------------ | ----------------------- | ------------------------------------------ |
| **AEC 回声消除** | ESP-SR 的 AFE 模块         | 通过 `afe_config_t` 开启，需要参考回采通道              |
| **NS 噪声抑制**  | ESP-SR AFE              | 支持 SSP 子空间投影等模式                            |
| **VAD 语音检测** | ESP-SR AFE              | 分 4 级灵敏度，小智用 MODE\_3                       |
| **唤醒词识别**    | ESP-SR 的 **WakeNet** 模型 | 本地离线推理，几百 KB 小模型                           |
| **3A 算法调度**  | ESP-DSP 向量指令加速          | S3 有专用 DSP 指令，C3 没有，所以 C3 板子 AEC/AGC 直接关掉了 |
| **网络协议栈**    | ESP-IDF 的 Wi-Fi / LwIP  | WebSocket/MQTT 长连接                         |
| **音频编解码**    | ESP-ADF 框架              | Opus 编解码、I2S 驱动、Codec 抽象层                  |
