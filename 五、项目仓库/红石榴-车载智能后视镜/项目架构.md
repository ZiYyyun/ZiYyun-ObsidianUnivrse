### 工程架构

具体开发入口：

> [!NOTE] 主程序入口
> `app/product_entry_jieli.c`

- product_app.c (line 50)：所有驱动、服务初始化，以及全局事件处理
- product_tasks.c (line 44)：创建 App Router 和 M1-M14
- `tasks`文件夹：从对应的 M 编号任务开始开发
- `middleware`：状态机、算法、业务策略
- `drivers`文件夹：芯片无关的器件驱动
- `platform/jieli`：文件夹：杰理 SDK、GPIO、UART、FreeRTOS 适配

### 编译流程

#### 使用codeblocks编译
杰理官方文档明确写的是：
- Windows SDK 默认支持 Code::Blocks
- 先安装 Code::Blocks
- 启动一次后关闭，让它生成基础配置
- 安装杰理 Windows 工具链
- 打开完整 SDK 目录里的 `.cbp`
- 选择目标后执行 Build

官方文档：[杰理开发环境安装说明](https://doc.zh-jieli.com/Tools/zh-cn/dev_tools/dev_env/index.html)

你以后按这个流程编译：

1. 关闭当前所有 Code::Blocks 窗口。
2. 双击仓库根目录的 [Open-SDK-Project.cmd](C:/Users/15839/Documents/红石榴/Proj/Open-SDK-Project.cmd)。
3. 脚本会自动同步产品代码，然后打开正确的 SDK 工程：

```
.build/fw-ac79-sdk/apps/wifi_story_machine/board/wl82/AC791N_WIFI_STORY_MACHINE.cbp
```

4. Code::Blocks 中选择 `Release`。
5. 执行 `Build -> Build` 或 `Ctrl+F9`。
6. 固件产物在：

```
.build/fw-ac79-sdk/cpu/wl82/tools/
```

不要直接打开这个文件编译：

```
code/wifi_story_machine/board/wl82/AC791N_WIFI_STORY_MACHINE.cbp
```

它只是仓库里的 SDK 覆盖文件，里面的 `../../../../cpu/...` 相对路径只有放在完整 SDK 的 `apps/wifi_story_machine/board/wl82` 下才成立。

#### 使用vscode编译


> [!NOTE] 所需插件：
> - task exporler
> - C/C++


执行 `code .` 的目录是：
```
C:\Users\15839\Documents\红石榴\Proj\.build\fw-ac79-sdk
```

也就是完整 SDK 根目录，里面必须能看到：
```
.vscode\
apps\
cpu\
tools\
Makefile
```

不要在下面这些目录执行：
```
code\
code\firmware\
.build\fw-ac79-sdk\apps\wifi_story_machine\
```

最简单的方式是在仓库根目录双击：
[Open-SDK-VSCode.cmd](C:/Users/15839/Documents/红石榴/Proj/Open-SDK-VSCode.cmd)

它会自动：
1. 把仓库里的最新产品代码同步到 SDK
2. 打开 SDK 根目录
3. 使用杰理提供的 `.vscode/tasks.json`
4. 保证 `make.exe`、`mkdir_win.exe`、`rm.exe` 加入 PATH

也可以手动执行：
```
cd "C:\Users\15839\Documents\红石榴\Proj\.build\fw-ac79-sdk"
code .
```

打开 VSCode 后：
1. 按 `Ctrl+Shift+P`
2. 选择 `Tasks: Run Build Task`
3. 选择：
```
ac791n_wifi_story_machine
```

不要选 `all`，因为 `all` 会编译 SDK 里的其他 demo。

需要注意一个重要规则：
```
真正的产品源码：
C:\Users\15839\Documents\红石榴\Proj\code\firmware

SDK 编译副本：
C:\Users\15839\Documents\红石榴\Proj\.build\fw-ac79-sdk\apps\firmware
```

产品代码仍以 `code/firmware` 为准。修改完产品代码后重新运行 [Open-SDK-VSCode.cmd](C:/Users/15839/Documents/红石榴/Proj/Open-SDK-VSCode.cmd)，它会重新同步到 SDK 再编译。不要只改 SDK 副本，否则改动不会回到仓库源码。

输出文件：
```
sdk.elf
jl_isd.fw
jl_isd.ufw
```
