### 引脚定义

| 引脚       | 功能           | 备注              |
| -------- | ------------ | --------------- |
| **PB4**  | 红线供电         | `PB4=1`：红线通电    |
| **PB3**  | 黄线供电         | `PB3=1`：黄线通电    |
| **PA15** | 绿线接R9电阻      | `PA15=1`：绿线连接R9 |
| **PB5**  | 黑线接R9电阻      | `PB5=1`：黑线连接R9  |
| **PB6**  | 模拟开关S1 (IO1) | 控制ADC输入源切换      |
| **PB7**  | 模拟开关S2 (IO2) | 控制ADC输入源切换      |



### 测压点

| 阶段      | 目标     | 控制引脚                        | ADC读数            |
| ------- | ------ | --------------------------- | ---------------- |
| 断线监测（1） | V1,V2  | PB3=1, PB4=1, PB6=0, PB7=0  | ADC1=V1, ADC0=V2 |
| 断线监测（2） | V3,V4  | PB3=1, PB4=1, PB6=0, PB7=1  | ADC1=V3, ADC0=V4 |
| 水浸监测    | V5,V6  | PB4=1, PB5=1, PB6=1, PB7=0  | ADC1=V5, ADC0=V6 |
| 水浸定位（1） | V7,V8  | PB3=1, PA15=1, PB6=1, PB7=0 | ADC1=V7, ADC0=V8 |
| 水浸定位（2） | V9,V10 | PB4=1, PB5=1, PB6=0, PB7=1  | ADC0=V9          |
|         |        | PB4=1, PB5=1, PB6=0, PB7=0  | ADC1=V10         |
