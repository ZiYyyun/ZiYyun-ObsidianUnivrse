#DS3553

### 初始化操作
	DS3553_Init(void)
```c
void Int_DS3553_Init(void)
{
    Int_DS3553_WriteRegister(PLUSE_EN, DS3553_SET); // 使能记步数输出
}
```

参考：[[DS3553-编写手册.pdf#page=9&selection=pulse_en|pulse_en ]] ，使能计步输出。这个功能位默认就是1。

### 读数据
	uint8_t Int_DS3553_ReadRegister(uint16_t mem_addr)
```c
uint8_t Int_DS3553_ReadRegister(uint16_t mem_addr)
{
    uint8_t receive_buffer = 0;
    // 开始传输：拉低CS引脚
    HAL_GPIO_WritePin(DS3553_CS_GPIO_Port, DS3553_CS_Pin, DS3553_RESET);
    Com_Delay_MS(3);
     HAL_I2C_Mem_Read(&hi2c1,DEVICE_READ,mem_addr,I2C_MEMADD_SIZE_8BIT,&receive_buffer,1,1000); 
    // 结束传输：拉高CS
    HAL_GPIO_WritePin(DS3553_CS_GPIO_Port, DS3553_CS_Pin, DS3553_SET);
    Com_Delay_MS(3);
    return receive_buffer;
}
```

参考手册中：[[DS3553-编写手册.pdf#page=6&selection=通信条件：CS 拉低。|通信条件：CS 拉低。]]   CS引脚拉低即表示开始读写数据


### 写入数据

```c
void Int_DS3553_WriteRegister(uint16_t mask, DS3553_STATE val)
{
    uint8_t defult_value = Int_DS3553_ReadRegister(USER_SET);
    if (val == DS3553_SET)
    {
        defult_value |= mask;
    } else{
        defult_value &= ~mask;
    }
    HAL_GPIO_WritePin(DS3553_CS_GPIO_Port, DS3553_CS_Pin, GPIO_PIN_RESET);
    Com_Delay_MS(3);
    HAL_I2C_Mem_Write(&hi2c1, DEVICE_WRITE, USER_SET, I2C_MEMADD_SIZE_8BIT, &defult_value, 1, 1000);
    HAL_GPIO_WritePin(DS3553_CS_GPIO_Port, DS3553_CS_Pin, GPIO_PIN_SET);
    Com_Delay_MS(10);
}
```

为了防止在修改具体某一位置的时候其它位收到影响，这里直接先读取初始值，判断之后进行位运算。
> 需要注意的是：在嵌入式开发中，不推荐使用三元运算符，因为编译后的执行速度相较于if要慢

### 获取步数
	uint32_t Int_DS3553_GetStep(void)
```c
uint32_t Int_DS3553_GetStep(void)
{
    uint32_t result = Int_DS3553_ReadRegister(STEP_CNT_L) + (Int_DS3553_ReadRegister(STEP_CNT_M) << 8) + (Int_DS3553_ReadRegister(STEP_CNT_H) << 16);
    return result;
}
```

这里直接定义一个`uint32_t`类型的变量，分别读取DS3553中低中高三个寄存器的值，位移之后赋给变量。
