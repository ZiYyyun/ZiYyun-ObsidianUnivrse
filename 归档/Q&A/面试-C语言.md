

### 基础

> [!QUESTION] 从源码到可执行文件，有哪四个过程

1. 预处理：处理掉空格、注释、宏定义 生成**处理后的源代码文件**
2. 编译： 将C代码编译为汇编，生成汇编文件
3. 汇编：将汇编编译为机器码，生成一个或若干个**目标（二进制）**文件
4. 链接：把文件**合并（标准库和其它库文件）**，生成可执行文件

- 32位：4字节
- 64位： 8字节

### 变量

> [!QUESTION] 变量的声明和定义有何区别？

声明：声明变量的类型、变量名，但不赋值
定义：声明变量的类型、变量名，还有值

声明不分配内存，定义会分配内存

> [!QUESTION] 变量和常量的差异？

|     | 变量      | 常量      |
| --- | ------- | ------- |
| 值   | 可改变     | 不可更改    |
| 赋值  | 运行时分配内容 | 编译时分配内容 |

> [!QUESTION] C语言有哪些定义常量的方式？
- `const` ： 需要指定数据类型，编译时有类型检查，有作用域，更安全 
- `#define`：预处理时的文本替换，没有类型检查、作用域。更安全


> [!QUESTION] 全局变量和局部变量有啥区别？

|       | 全局变量             | 局部变量        |
| ----- | ---------------- | ----------- |
| 作用域   | 整个源文件            | 函数/代码块内部    |
| 生命周期  | 整个程序执行期间         | 函数/代码块被调用期间 |
| 储存位置  | 全局静态区            | 程序栈区        |
| 默认初始化 | 0或者NULL（指针是NULL） | 未定义         |

### 宏

> [!QUESTION] 什么是条件编译？应用场景？

条件编译是C语言的一个预处理指令，用于根据不同条件编译或排除代码。
条件编译可以在函数编译阶段通过指令来根据条件判断某段代码是否参与编译，从而实现不同版本的代码生成。使用`if` `#ifdef` `#ifndef` `#else` `#elif` `#endif`等预处理指令实现

应用场景：

| 调试代码  | 在代码调试阶段，可以通过条件编译来决定临时禁用某些代码块，方便调试 |
| ----- | --------------------------------- |
| 功能开关  | 根据**编译选项**或宏定义来控制是否启用某段代码         |
| 跨平台编译 | 可以使用条件编译语句来为不同的操作系统/硬件平台生成特定代码    |

### 数组

> [!QUESTION] 数组的特点&数组大小的计算

- 数组的元素在内存中紧密有序排列
- 数组的长度在初始化时被确定，过后无法更改
- 可以直接通过数组下标来访问指定元素

数组大小的计算
```c
sizeof(arr) / sizeof(arr[0]);
```

> [!QUESTION] 字符串的本质是什么

是字符数组。在内存中，字符串是连续紧密的**字符序列**
字符串以`\0 (ASCII码0)`结束

> [!QUESTION] 对于字符串而言，`sizeof()`与`strlen()`有啥区别

- `sizeof()`：返回整个字符串的真实长度（包含`\0`）
- `strlen()`：返回字符串中实际字符的个数（不包括`\0`）


> [!QUESTION] 多维数组是什么，储存模式是怎样的

数组的元素也是数组，这就是多维数组

多维数组按照**连续的**、**行优先**的形式储存

### 指针

> [!QUESTION] 两个指针相减会发生什么

会得到两个指针之间元素的个数
指针之间只能减，不能做加法

> [!QUESTION] 指针加减整数会得到什么结果

指针加减整数，表示指针所指向的内存地址的移动。
指针移动多少与数据类型有关，数据类型占据多少字节，每单位就移动多少字节。

> [!QUESTION] 指针能否比较大小

指针比较大小，比较的就是指针自己所指向地址的大小


> [!QUESTION] 指向首元素的指针和数组名有什么不同


|          | 类型  | sizeof  | &取地址   | +1    | 解引用   | 可变性    |
| -------- | --- | ------- | ------ | ----- | ----- | ------ |
| 数组名      | *   | 数组的大小   | 首元素地址  | 下一个元素 | 首元素的值 | 不可重新赋值 |
| 指向首元素的指针 | []  | 指针本身的大小 | 指针本身地址 | 下一个元素 | 首元素的值 | 可重新赋值  |


### 结构体

> [!QUESTION] 结构体变量和结构体指针在访问成员时的差异

- 结构体变量包含着结构体的数据。可以直接使用`.`来访问结构体成员
- 结构体指针包含结构体的地址，需要用`->`来访问成员

> [!QUESTION] 结构体的长度如何计算

结构体长度是成员长度之和，但是为了访问效率，编译器会进行内存对齐：
- 第一个成员的偏移量为0.
以8字节为例：
- 不满8字节的成员，该成员首地址是其自身数据类型大小的整数倍 
- 超过8字节的成员，首地址是8的整数倍
- 若内嵌结构体，则内嵌结构体中成员的首地址按照结构体中最大成员类型大小来
- 数组可以拆开，看成n个元素，不用整体看成一个类型
最后结构体整体补齐：
- 不足8字节的成员，大小补齐为**最大成员**类型大小的整数倍
- 大于8字节的成员，补齐为8的整数倍
- 内嵌结构体也要补齐

> [!QUESTION] 结构体与联合体差异

- 结构体每个成员都有单独的内存空间，互不干涉
- 联合体所有成员共同使用一块内存，同时只有一个成员能够得到内存的使用权。一个联合体的总长度应该至少能容纳其中最大的那个成员，联合体需要内存补齐

### 函数
> [!QUESTION] 给函数传参时，传入值和转入指针有啥区别

- 传入值：函数内部对形参操作，并不能影响到实参。通常用于传基本数据类型（整数、浮点数）
- 传指针：实参的地址会传给函数，函数可以通过指针访问实参所指向的地址的数据，对实参指向数据的修改函数内外都可见。   通常用于传递数组、结构体等较大的。避免复制整个数据块



### 内存
> [!QUESTION] 介绍一下C语言内存模型

| 栈区（Stack）     | 函数的参数、局部变量      |
| ------------- | --------------- |
| 堆区（Heap）      | 提供程序动态申请的内存空间   |
| 全局静态区（Static） | 全局变量、静态变量和字符串常量 |
| 程序代码区         | 函数体的二进制代码       |

> [!QUESTION] 什么是内存泄漏

内存泄漏是程序在执行的过程中由于申请的占空间由于某种原因无法收回或者没有被收回所导致的浪费。它会导致程序变慢甚至系统崩溃。
- 偶发性内存泄漏：在特定条件下触发内存泄漏
- 常发性内存泄漏：泄漏内存的代码被多次执行到
- 一次性内存泄漏：内存泄漏的代码只会被触发一次
- 隐式内存泄漏：程序运行过程中不断泄漏内存，直到程序结束之后才释放
