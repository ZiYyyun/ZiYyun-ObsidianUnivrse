

> [!QUESTION] **为什么会需要中断（Interrupt）？**
- 如果没有中断，CPU会怎样工作？
- 为什么轮询（Polling）效率低？
- 中断发生后CPU内部到底发生了什么？
- 为什么ISR不能执行太久？
- 为什么还会出现中断优先级和中断嵌套？


### 中断的作用
中断指MCU在轮询执行任务时，发生某些特定紧急事件，此时我们需要MCU立刻停止当前任务，马上“插播广告”，插播完成之后恢复主任务。为保证完成这些操作的同时保证主任务不受影响，于是便有了**中断**。

### 轮询的效率
你说的这个“效率”的高低，其实是相对的。如果我们没有多任务并发的需求时，可以说：这个轮询的“效率”是够用的。
但是当任务的**实时性**有所要求时，轮询便力不从心了，为了实现多任务同时实时运行，那么我们就需要给MCU加上RTOS

### 中断的流程
> 我们先假设一个场景：
```
main函数 -> while(1) { HAL_USART_Transmit("hello") }
```
此时MCU向串口循环发送"hello"，此时我们按下`Key1`，发生了如下一系列事件：

```
按键按下    ---->    触发下降沿中断
中断标志位置1 -->     触发中断服务函数ISR

```







> [!WARNING] Tip
> 假设你的程序跑着跑着，你想**临时关闭**这个 40 号中断（比如在进行某个极其敏感的 ADC 采样时，绝对不能被打断），采样完了再打开。
在 CMSIS 库中，有个函数叫 `NVIC_DisableIRQ(EXTI15_10_IRQn);`。
