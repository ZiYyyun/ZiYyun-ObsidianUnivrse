
中断是指 CPU 对系统发生某事件时的一种响应，即CPU 暂停正在执行的程序，在保留现场后，自动地转去执行该事件的中断处理程序，执行完后，再返回到原程序的断点处继续执行。

---

- 为什么ISR不能执行太久？

### 中断的作用
中断指MCU在轮询执行任务时，发生某些特定紧急事件，此时我们需要MCU立刻停止当前任务，马上“插播广告”，插播完成之后恢复主任务。为保证完成这些操作的同时保证主任务不受影响，于是便有了**中断**。

### 轮询的效率
你说的这个“效率”的高低，其实是相对的。如果我们没有多任务并发的需求时，可以说：这个轮询的“效率”是够用的。
如果采用轮询的方式，那么CPU不知道什么时候来数据，就会一直轮询，浪费了大量资源


> [!WARNING] 轮询一定比中断快？
> 如果是高频任务，轮询可能已经够用了。如果还要选择中断方式的话，中断开销可能远大于轮询



### 中断的流程

```
外部引脚信号 ──┐
              ▼
        ┌─────────────┐
        │  边沿检测器   │  ← 由 RTSR/FTSR 配置决定检测哪种边沿
        └──────┬──────┘
               │ 检测到有效边沿
               ▼
        ┌─────────────┐
        │  产生触发脉冲 │
        └──────┬──────┘
               │
      ┌────────┴────────┐
      ▼                 ▼
 ┌─────────┐      ┌─────────┐
 │ EXTI_PR │      │ EXTI_PR │   ← 脉冲到达，硬件自动把 PR 对应位置 1
 │  置 1   │      │  置 1    │
 └────┬────┘      └────┬────┘
      │                │
      ▼                ▼
 ┌─────────┐      ┌─────────┐
 │ EXTI_IMR│      │ EXTI_EMR│   ← 检查屏蔽位
 │  = 1 ?  │      │  = 1 ?  │
 └────┬────┘      └────┬────┘
      │ 是              │ 是
      ▼                ▼
 ┌─────────┐      ┌─────────┐
 │  NVIC   │      │ 事件输出 │
 │中断请求  │      │ 脉冲     │
 └────┬────┘      └─────────┘
      ▼
 CPU 跳转到对应 ISR
```




> 我们先假设一个场景：
```
main函数 -> while(1) { HAL_USART_Transmit("hello") }
```
此时MCU向串口循环发送"hello"，此时我们按下`Key1`，发生了如下一系列事件：

```c
按键按下 
GPIOx_IDR寄存器读到低电平：触发下降沿中断
EXTI_FTSR检测到下降沿：触发中断服务函数ISR 
中断标志位(EXTI_PR)置1    //[!Describe] 这个PR寄存器由硬件自动置1
EXTI_IMR 允许 + NVIC 使能
进入 ISR
清除 EXTI_PR
执行按键任务
```


> [!WARNING] Tip
> 假设你的程序跑着跑着，你想**临时关闭**这个 40 号中断（比如在进行某个极其敏感的 ADC 采样时，绝对不能被打断），采样完了再打开。
在 CMSIS 库中，有个函数叫 `NVIC_DisableIRQ(EXTI15_10_IRQn);`。


### 中断相关寄存器



```c
typedef struct
{
  __IO uint32_t IMR;
  __IO uint32_t EMR;
  __IO uint32_t RTSR;
  __IO uint32_t FTSR;
  __IO uint32_t SWIER;
  __IO uint32_t PR;
} EXTI_TypeDef;
```

| 寄存器             | 全称                        | 作用                        |
| --------------- | ------------------------- | ------------------------- |
| **EXTI\_IMR**   | Interrupt Mask Register   | 中断屏蔽。允许该线产生中断请求到 NVIC     |
| **EXTI\_EMR**   | Event Mask Register       | 事件屏蔽。允许该线产生事件脉冲（不经过 NVIC） |
| **EXTI\_RTSR**  | Rising Trigger Selection  | 上升沿触发选择。该线检测上升沿           |
| **EXTI\_FTSR**  | Falling Trigger Selection | 下降沿触发选择。该线检测下降沿           |
| **EXTI\_SWIER** | Software Interrupt Event  | **软件中断事件**。手动在该线上产生一个触发脉冲 |
| **EXTI\_PR**    | Pending Register          | 挂起寄存器。该线有未处理的中断/事件请求      |

### 获取标志位状态函数

```c
FlagStatus EXTI_GetFlagStatus(uint32_t EXTI_Line)
{
  FlagStatus bitstatus = RESET;
  /* Check the parameters */
  assert_param(IS_GET_EXTI_LINE(EXTI_Line));
  if ((EXTI->PR & EXTI_Line) != (uint32_t)RESET)    //[!describe]如果这个EXTI_PR和EXTI_Line同时为高位，那么if的条件就成立
  {
    bitstatus = SET;           
  }
  else
  {
    bitstatus = RESET;
  }
  return bitstatus;
}
```
