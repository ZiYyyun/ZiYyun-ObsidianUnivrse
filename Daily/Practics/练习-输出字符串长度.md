
### 定义变量
```c
char string1[] = "hello";
char string2[] = "0000000";
char string3[] = "abccdef3333333"; 
```

### 实现函数
	int my_strlen(char str[])
```c 
	int i,len = 0;
	while(!(*str == '\0')) { len ++; str++; }
	return len;
```
字符串在结尾的时候，会返回`\0`这个值，当然也等同于`0`。



> [!NOTE] tip
> 其实我们写`str`，获取到的是**地址**。而`*str`是**解引用**，即获取这个地址里的内容



### 主函数
	int main()
```c

int main(int argc, char** argv) {
   	printf("字符串的长度是%d", my_strlen(string1));
   	printf("字符串的长度是%d", my_strlen(string2));
   	printf("字符串的长度是%d", my_strlen(string3));	
	return 0;
}
```
